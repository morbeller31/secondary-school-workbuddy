# Privacy and safeguarding

This repository is designed as a public template. Do not commit information that identifies a child or family.

Keep the following outside Git and outside public issue discussions:

- names, dates of birth, addresses, school names, student numbers, photographs, and contact details;
- diagnoses, medication information, health records, psychological assessments, IEPs, and school reports;
- passports, visas, birth certificates, invoices, account details, credentials, and access codes;
- homework files containing identifying information;
- copyrighted textbooks, workbooks, literature editions, or answer books.

Use a private workspace for learner-specific information. Record only the minimum information needed for educational support and follow the privacy, consent, and safeguarding requirements that apply in your location and school.

If sensitive information is committed accidentally, remove access immediately and treat it as exposed. Deleting it in a later commit does not remove it from Git history.
